# ORPHEUM — Midnight Siege

A browser FPS with hand-drawn sprites in a true 3D cinema level.
Built with Unity 6.3 LTS and published as a static GitHub Pages site.

## Play

Open the site's GitHub Pages URL in a desktop browser, wait for loading,
then click **Играть** to enable audio and capture the mouse.

WASD: movement; mouse: aim; left mouse: fire; R: reload; E: interact;
1/2 or wheel: weapons; Shift: run; Space: jump; C/Ctrl: crouch;
Esc: pause and release cursor; F4: retro resolution.

Find the yellow access card at the ticket counter, restore projector power
upstairs, and use the panel at the end of the service corridor to escape.

Only compiled browser files are published in this repository.
The Unity build uses gzip with JavaScript decompression fallback and does
not require custom HTTP headers or cross-origin isolation.
